# Illustration provenance

- `pusht_dream.gif` is a historical teaching visualization from the development
  implementation. It renders predicted and actual states from an earlier recipe;
  it is not a result from the current matched study. The README labels this scope.
- `architecture.png` is rendered from the current paper's architecture schematic.
  Its source generator is `reproduction/analysis/architecture_figure.py` and its
  vector form can be regenerated with `python reproduce.py figures`.

Source paths and hashes are recorded in `SOURCE_PROVENANCE.json`. The underlying
Push-T demonstration dataset retains its upstream terms and is not bundled here.
